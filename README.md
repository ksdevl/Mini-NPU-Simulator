# Mini-NPU-Simulator

Python으로 NPU의 기본 연산 구조인 MAC(Multiply Accumulate)을 구현하고, 입력 패턴과 필터의 유사도를 비교하는 시뮬레이터로서, 행렬 크기에 따른 연산을 수행하고, Cross와 X 패턴의 점수를 비교하여 결과를 분류한다.

## 3. 미션 구현 내용

### 3-1. MAC 연산 구현

MAC은 Multiply Accumulate의 약자로, 두 행렬의 같은 위치에 있는 값을 곱하고 결과를 누적하는 연산이다.

\[
MAC=\sum_{i=1}^{N}\sum_{j=1}^{N} A_{ij}\times B_{ij}
\]

Python의 중첩 반복문을 이용하여 각 원소의 곱셈과 누적 합산을 직접 구현하였다.

```python
def mac_operation(input_matrix, filter_matrix):
    score = 0

    for i in range(len(input_matrix)):
        for j in range(len(input_matrix)):
            score += input_matrix[i][j] * filter_matrix[i][j]

    return score
```

행렬 크기가 N×N인 경우 필터 하나를 비교하는 데 N²회의 곱셈과 누적 연산을 수행한다.

### 3-2. Cross / X 패턴 분류

입력 패턴과 두 필터의 MAC 점수를 각각 계산하고, 더 높은 점수를 얻은 필터의 유형으로 분류한다.

| 구분 | 패턴 형태 | 설명 |
|---|---|---|
| Cross | 십자형 | 가운데 행과 열에 값이 배치된 패턴 |
| X | 대각선형 | 두 대각선에 값이 배치된 패턴 |

- 입력 패턴과 필터의 같은 위치에 있는 값끼리 곱한다.
- 각 곱셈 결과를 모두 더해 MAC 점수를 계산.
- Cross와 X의 점수를 비교하여 높은 점수를 얻은 유형으로 판정.
- 두 점수의 차이가 1e-9 미만이면 `UNDECIDED`로 처리

### 3-3. 입력 모드

| 모드 | 기능 | 설명 |
|---|---|---|
| Mode 1 | 수동 입력 | 3×3 필터 A, 필터 B 및 입력 패턴을 직접 입력하여 비교 |
| Mode 2 | JSON 자동 분석 | data.json에 저장된 테스트 패턴을 불러와 자동으로 분석 |
| 보너스 | 패턴 자동 생성 | 행렬 크기 N을 입력하여 Cross/X 필터 자동 생성 |

Mode 1에서는 사용자가 직접 행렬을 입력하여 MAC 연산과 패턴 분류 과정을 확인할 수 있다.

Mode 2에서는 JSON 파일의 테스트 데이터를 불러와 여러 행렬 크기의 패턴을 자동으로 분석한다.

보너스에서는 행렬 크기를 지정하여 Cross/X 필터 자동 생성한다.

## 4. JSON 데이터 관리 및 검증

### 4-1. 데이터 구조

`data.json`에 필터와 테스트 패턴을 저장하여 프로그램 코드와 테스트 데이터 분리

```json
{
  "meta": {},
  "filters": {
    "size_5": {
      "cross": [],
      "x": []
    },
    "size_13": {
      "cross": [],
      "x": []
    },
    "size_25": {
      "cross": [],
      "x": []
    }
  },
  "patterns": {
    "size_5_1": {
      "input": [],
      "expected": "Cross"
    }
  }
}
```

- `meta`: 데이터 관련 정보
- `filters`: 행렬 크기별 Cross 및 X 필터
- `patterns`: 입력 패턴과 기대 판정 결과

### 4-2. 데이터 검증 및 예외 처리

JSON 데이터를 불러온 후 다음 항목을 검증하도록 구현

- JSON 파일의 존재 여부 및 데이터 구조
- 행렬 크기와 행·열의 개수 일치 여부
- 행렬 내부 값의 숫자 형식 여부
- 잘못된 데이터에 대한 오류 처리

판정 결과의 표기를 통일하기 위해 `+`, `cross`는 `Cross`로, `x`는 `X`로 정규화한다.

잘못된 데이터가 발견되더라도 전체 프로그램이 중단되지 않도록 해당 테스트 케이스를 FAIL 처리하고, 실패 원인을 출력하도록 구성

## 5. 보너스 미션

### 5-1. 2차원 배열과 1차원 배열 연산 비교

2차원 행렬을 1차원 배열로 변환하여 동일한 데이터를 대상으로 MAC 연산을 수행하고, 두 방식의 연산 시간을 비교하는 확장 기능.

- 2차원 배열: 행과 열의 인덱스로 데이터에 접근
- 1차원 배열: 행 우선 순서(Row-major)로 변환하여 인덱스로 접근
- 두 방식의 연산 결과가 동일한지 확인
- 동일한 조건에서 반복 측정하여 평균 실행 시간 비교

2차원 배열의 위치 `(i, j)`는 1차원 배열에서 다음과 같이 표현할 수 있다.

```python
index = i * N + j
```

성능 비교는 동일한 입력 데이터와 행렬 크기, 반복 횟수를 기준으로 수행


### 5-2. 패턴 자동 생성

사용자가 행렬 크기 N을 입력하면 해당 크기에 맞는 Cross와 X 필터를 자동으로 생성하는 기능을 구현하였다.

**구현 기능**
- `generate_cross_filter(size)`: 중앙 행과 중앙 열을 기준으로 Cross 필터 생성
- `generate_x_filter(size)`: 두 대각선을 기준으로 X 필터 생성
- `print_matrix()`: 생성된 필터를 행렬 형태로 출력
- `run_pattern_generator()`: 크기 입력, 필터 생성 및 검증 실행

**생성 규칙**
- Cross: 중앙 행과 중앙 열에 1을 배치하고 나머지는 0으로 설정
- X: 두 대각선 위치에 1을 배치하고 나머지는 0으로 설정
- 홀수 크기는 가운데 행과 열을 사용하며, 짝수 크기는 가운데 두 행과 열을 사용한다.
- 입력 크기는 양의 정수인지 검증하며 잘못된 입력은 재입력을 유도한다.

생성된 필터는 기존 MAC 연산 함수에 전달하여 점수를 계산하고, Cross와 X의 유사도를 비교할 수 있도록 구성하였다.

## 6. 실행 방법

### 6-1. 프로그램 실행

프로젝트 폴더에서 다음 명령어 실행

```powershell
py main.py
```

### 6-2. Mode 1 - 수동 입력

메뉴에서 `1`을 선택하고 필터 A, 필터 B, 입력 패턴을 순서대로 입력

각 행은 숫자 3개를 공백으로 구분하여 입력

```text
0 1 0
1 1 1
0 1 0
```

각 행렬의 입력이 완료되면 필터 A와 필터 B의 MAC 점수 및 비교 결과를 확인할 수 있다.

두 필터의 점수가 같으면 `판정 불가`로 표시하고, 점수가 더 높은 필터를 최종 결과로 출력한다.

### 6-3. Mode 2 - JSON 자동 분석

메뉴에서 `2`를 선택하면 `data.json`의 테스트 데이터를 자동으로 불러온다.

각 테스트 패턴에 대해 MAC 연산과 판정을 수행하고, 기대 결과와 실제 결과를 비교하여 PASS/FAIL 출력

`0`을 입력하면 프로그램 종료

### 6-4. 패턴 자동 생성

메뉴에서 `3`을 선택하면 생성할 행렬 크기 N을 입력받는다.

입력한 크기에 맞춰 Cross와 X 필터를 자동 생성한다.

- Cross 필터: 가운데 행과 열에 1.0 배치
- X 필터: 두 대각선에 1.0 배치
- 생성된 행렬의 크기 및 데이터 검증
- 생성된 Cross 패턴을 이용한 MAC 연산 및 판정 결과 확인
- 입력 크기는 1부터 1000까지 허용하며, 범위를 벗어나거나 잘못된 입력은 재입력을 요구한다.

예를 들어 N에 `5`를 입력하면 5×5 크기의 Cross 및 X 필터를 생성한다.

- 두 배열 방식의 MAC 계산 결과가 모두 5.0으로 동일하게 나타났다.
- 2차원 배열의 평균 실행 시간은 0.001255ms, 1차원 배열은 0.000802ms로 측정되었다.
- 이번 측정에서는 1차원 배열의 실행 시간이 약 36.1% 짧게 나타났다.
- 배열 구조에 따라 데이터 접근 및 연산 실행 시간에 차이가 발생할 수 있음을 확인하였다.
- 해당 결과는 3×3 테스트 데이터에 대한 측정값이며, 모든 행렬 크기에서 동일한 성능 차이가 발생한다고 단정할 수는 없다.

### 7-7. 패턴 자동 생성 테스트

사용자가 입력한 행렬 크기 N에 따라 Cross와 X 필터가 정상적으로 생성되는지 검증하였다.

**테스트 조건**
- 테스트 크기: 3×3, 5×5, 13×13, 25×25
- Cross: 중앙 행과 중앙 열에 1 배치
- X: 두 대각선에 1 배치
- 생성 결과의 행과 열 개수 및 숫자 데이터 검증
- 생성된 필터를 MAC 연산에 활용하여 점수 계산 확인

**테스트 결과**

| 행렬 크기 | Cross의 1 개수 | X의 1 개수 | 검증 결과 |
|---|---:|---:|---|
| 3×3 | 5 | 3 | PASS |
| 5×5 | 9 | 5 | PASS |
| 13×13 | 25 | 13 | PASS |
| 25×25 | 49 | 25 | PASS |

**결과 분석**

- 입력한 N에 맞춰 Cross와 X 필터가 자동 생성되는 것을 확인하였다.
- 각 행렬의 행과 열 개수가 입력한 크기와 일치하는지 검증하였다.
- Cross는 중앙 행과 열, X는 두 대각선에 값이 배치되는 규칙을 적용하였다.
- 생성된 필터를 기존 MAC 연산에 연결하여 패턴 점수를 계산할 수 있도록 확장하였다.
- 이를 통해 필터를 직접 작성하지 않고도 다양한 행렬 크기의 패턴을 생성하고 연산에 활용할 수 있게 되었다.

### 7-8. 시간 복잡도 분석

MAC 연산은 N×N 행렬의 모든 원소를 한 번씩 곱하고 누적하므로, 행렬 크기 N에 대해 총 N²회의 반복 연산을 수행한다.

- 3×3 행렬은 9회, 5×5 행렬은 25회 연산한다.
- 13×13 행렬은 169회, 25×25 행렬은 625회 연산한다.
- 행과 열을 순회하는 중첩 반복문을 사용하므로 시간 복잡도는 O(N²)이다.
- 필터 하나를 비교할 때 N²회 연산하며, Cross와 X 두 필터를 비교하면 총 2N²회 연산한다.
- 따라서 행렬의 한 변 길이가 2배가 되면 MAC 연산량은 약 4배가 된다.
- 실제 실행 시간은 Python 반복문 처리 비용, 데이터 접근, 운영체제 및 실행 환경의 영향을 받으므로 연산 횟수와 정확히 비례하지 않을 수 있다.
- 성능 측정 결과에서도 행렬 크기가 증가할수록 평균 실행 시간이 증가하는 경향을 확인할 수 있다.
- 본 시뮬레이터는 CPU에서 순차적으로 MAC 연산을 수행하며, 실제 NPU의 병렬 하드웨어 성능을 측정하는 프로그램은 아니다.
